<h2 style="text-align: center;">What is a Compiler?</h2>
<p style="text-align: justify;">A compiler is a an already made program, which one can use to make new programs.</p>
<p class="_Tgc" style="text-align: justify;">A compiler compiles our code written in a specific language (say C++), and translates it in the machine language, for the Computer (or any other device), which then understands it and makes our program run.</p>
<h2 class="_Tgc" style="text-align: center;">What is IDEOne and why should I even bother about it?</h2>
<p style="text-align: justify;">IDEOne is an online compiler and debugging tool which allows one to compile source code and run it online without the need of any other software. Just click on the IDEOne logo to start coding.</p>
<h4 style="text-align: justify;"><strong><a href="http://ideone.com/" target="_blank" rel="noopener noreferrer"><img class="aligncenter wp-image-1504 size-medium" src="/wp-content/uploads/2016/01/ideone-fi-300x300.jpg" alt="IDEOne" width="300" height="300" /></a>Some great benefits -</strong></h4>
<ul style="text-align: justify;">
    <li><strong>No prerequisites</strong>, i.e. other software needed</li>
    <li><strong>Free</strong> to use</li>
    <li><strong>No need to sign-up</strong>. Even though you can become a registered user for added benefits like extra 10 seconds of Execution time.</li>
    <li>Supports <strong>60+ languages</strong></li>
    <li>Always <strong>up to date</strong> with the latest coding conventions</li>
    <li>Include <strong>sample codes</strong> for beginners</li>
    <li><strong>Share</strong> your content over the internet. You can choose your program to be public, secret, or private.</li>
</ul>
<h3 style="text-align: center;">Are there any limitations, of this free service?</h3>
<p style="text-align: justify;">Unfortunately, yes there are a few limitations, but they won't limit your coding potential unless you are a professional coder. Following are the limitations -</p>
<ul style="text-align: justify;">
    <li>The compilation should not take more than 10 seconds.</li>
    <li>Execution time should not take more than 5 seconds; 15 seconds for logged-in users.</li>
    <li>Your program cannot use more than 256MB memory.</li>
    <li>Your code shouldn't exceed the size of 64KB.</li>
    <li>Your program can't access the internet.</li>
</ul>
<p style="text-align: justify;">Even, if you confront any of these limitations ever, you can just download your program, and run it on any other offline compiler.</p>
