<h1 style="text-align: center;">Hi Guys,</h1>
<p style="text-align: justify;">Long time no see, but here we are back again, to talk about an app, which we didn't knew existed. No, I mean really, it's a fairly new app with about 5K downloads. But yet has a lot of potential. Let's talk about <strong>MoveIt</strong>.</p>
<h2 style="text-align: center;">What is MoveIt?</h2>
<p style="text-align: justify;">As the name states, MoveIt is a simple to use app, with a very naïve user interface which helps the user transfer media to SD Card, negating the use of a file manager app.</p>
<h2 style="text-align: center;">Where to get MoveIt?</h2>
<p style="text-align: justify;">This app is currently available on the Google <a href="https://play.google.com/store/apps/details?id=moveit.movetosdcard.cleaner" target="_blank" rel="noopener noreferrer">Play Store</a>, for Android Lollipop and above.</p>
<h2 style="text-align: center;">Special Notable Features</h2>
<ul>
    <li>
<h4>Internal to External or vice versa</h4>
[caption id="attachment_2031" align="alignright" width="169"]<a href="/2017/07/moveit-move-media-to-sd-card-whats-that/moveit-cleaner/#main" rel="attachment wp-att-2031"><img class="size-medium wp-image-2031" src="/wp-content/uploads/2017/07/Moveit-Cleaner-169x300.jpeg" alt="MoveIt Cleaner" width="169" height="300" /></a> MoveIt Cleaner[/caption]</li>
</ul>
<p style="text-align: justify;">Well that's pretty self-explanatory, that this app will help you <strong>transfer</strong> pictures and other medias from phone's internal memory to an external memory card.</p>
<ul>
    <li>
<h4>Cleaner</h4>
</li>
</ul>
<p style="text-align: justify;">It helps in cleaning junk files, and has a striking resemblance to CleanMaster app, but unlike that app it <strong>lacks</strong> in showing exactly which files, it is going to delete.</p>
<p style="text-align: justify;">That is it will report 2 apk files are to be deleted leaving the user with options such as to delete or not, but not allowing the user to check which apk files are those within the app.</p>
<p style="text-align: justify;">So, that's a negative point for the app.</p>
<ul>
    <li>
<h4>Easy to use UI</h4>
</li>
</ul>
I will give it some points for being simple to use. A simplistic UI without too many buttons or features give it an appealing look, provided that it <strong>remains ad-free</strong> in the future as well.
<ul>
    <li>
<h4>Auto Transfer</h4>
</li>
</ul>
<p style="text-align: justify;">This feature, in theory, should automatically detect new files in a specified folder and automatically move it to another specified folder on the memory card.</p>
<p style="text-align: justify;">One can use this feature to move pictures taken from the phone's camera to the microSD.</p>
<p style="text-align: justify;">But there are numerous downsides to this feature as -</p>
<ol>
    <li style="text-align: justify;">It requires the app to be working in the background all the time, continuously consuming phone's resources like battery and working speed (RAM).</li>
    <li style="text-align: justify;">Most camera apps these days, have the setting to automatically save the pictures in the desired folder. Especially if the app only supports newer devices such as Android Lollipop and above.</li>
    <li style="text-align: justify;">It doesn't work. It didn't work for <strong>Samsung Galaxy S4</strong> or<strong> Moto X2</strong>. My co blogger Siddhant was pretty much disappointed by this app.</li>
</ol>
<h2 style="text-align: center;">Final Verdict</h2>
My final verdict is this app is in its initial stages, and might do well in the future. MoveItApps, whatever you do with this app, don't change the simplistic approach of its UI, that's its biggest feature, yet. Also I like the name, reminds me of a song from Madagascar.
If you enjoyed the app, do tell us in the comments. Here is the download link again, <a href="https://play.google.com/store/apps/details?id=moveit.movetosdcard.cleaner" target="_blank" rel="noopener noreferrer">MoveIt</a>.
Also comment, what new features you want in the app, the App Developer will surely read your comments and may add those features in near future.
