<h1 style="text-align: center;">Hi Guys,</h1>
<p style="text-align: justify;">Today we are discussing how to change the default browser of an iOS device, that is <a href="http://en.wikipedia.org/wiki/Safari_(web_browser)" target="_blank" rel="noopener noreferrer">Safari</a> to any other browser, like Google Chrome, Opera Mini, etc.</p>
<h2 style="text-align: center;">How can I change the default browser in my iDevice?</h2>
<ul>
	<li style="text-align: justify;">First of all, you will need a <strong>Jailbroken</strong> iOS Device. If you can find an app named Cydia, then your iDevice is jailbroken. Else you'll need to jailbreak it, try <a href="/2015/03/ways-of-rooting/" target="_blank" rel="noopener noreferrer">Jailbreaking made easy</a>.</li>
</ul>
<ul>
	<li style="text-align: justify;">Then download any other browser which you want to make your default browser like <a href="https://itunes.apple.com/in/app/chrome-web-browser-by-google/id535886823?mt=8" target="_blank" rel="noopener noreferrer">Google Chrome</a>, <a href="https://itunes.apple.com/in/app/opera-mini-web-browser/id363729560?mt=8" target="_blank" rel="noopener noreferrer">Opera Mini</a>, etc.</li>
</ul>
<ul>
	<li style="text-align: justify;">Open Cydia, and search for BrowserChooser. Install it.</li>
</ul>
<ul>
	<li style="text-align: justify;">After installation, go to Settings &gt; BrowserChooser. You will find a list of installed browsers, choose anyone, Or choose none, if you want it to be Android style, asking every time you click a link.</li>
</ul>
<ul>
	<li style="text-align: justify;">You are done.</li>
</ul>
<p style="text-align: justify;">Now whenever, Safari opened automatically, for e.g. when clicking any link, or searching via <a href="http://en.wikipedia.org/wiki/Siri" target="_blank" rel="noopener noreferrer">Siri</a>; Instead of Safari, the link will open in your chosen browser.</p>
<h2 style="text-align: center;">Who's the developer?</h2>
<p style="text-align: justify;">BrowserChooser tweak was developed by <a href="https://twitter.com/rpetrich" target="_blank" rel="noopener noreferrer"><strong>Ryan Petrich</strong></a>. He is one of the well-known Jailbreak Developers and iOS Hacker. This tweak along with other great tweaks are also available on his own Repo <em>http://rpetri.ch/repo/</em>.</p>
<h2 style="text-align: center;">Will it support my device?</h2>
<p style="text-align: justify;">It will most probably work with all iDevices running any iOS. But developers say it supports iOS 5 and above.</p>
<p style="text-align: justify;">I personally tested it on my iPhone 4S running iOS 8.1.2. It didn't worked all the time. So I switched to Browser Changer. But everyone should consider BrowserChooser first because it is made by a well known iOS Developer, Ryan Petrich.</p>
<h2 style="text-align: center;">In which Repo will I find it?</h2>
<p style="text-align: justify;">It is readily available for <strong>free</strong> on the BigBoss Repo as well as Ryan’s own Beta Repo in Cydia. Simply search for BrowserChooser in the Search section, and install it. If you are unsure how to install, see our <a href="/2015/04/cydia/" target="_blank" rel="noopener noreferrer">post</a> or <a href="https://www.youtube.com/watch?v=1IeTiRvkc9k" target="_blank" rel="noopener noreferrer">YouTube video</a> to get assistance regarding installations in Cydia. BigBoss Repo - <em>http://apt.thebigboss.org/repofiles/cydia/</em> and Ryan Petrich's Repo - <em>http://rpetri.ch/repo/</em></p>
<h3 style="text-align: center;">Note in case of failure -</h3>
<p style="text-align: justify;">In case BrowserChooser isn't working as expected or isn't supporting your iOS version or your refereed Browser, you can try Browser Changer Tweak. It is a similar tweak.</p>
