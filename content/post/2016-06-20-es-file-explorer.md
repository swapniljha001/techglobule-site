<h1 style="text-align: center;">Hi Guys,</h1>
<p style="text-align: justify;">Today we will discuss about a simple but amazing File manager, namely ES File Explorer.</p>
<h2 style="text-align: center;">What is a File Manager? Why use it?</h2>
<p style="text-align: justify;">A file <span class="_Tgc">manager or file browser is an app that provides a user friendly interface to manage the files and folders in a specific device. Some common uses, might be -</span></p>
<ul style="text-align: justify;">
 	<li>Sorting different photos in different albums.</li>
 	<li>Or maybe searching for a specific movie or song to share.</li>
 	<li>This list is endless, that's why I'm not into it.</li>
</ul>
<h2 style="text-align: center;">What is ES File Explorer?</h2>
<p style="text-align: justify;">ES File Explorer (File Manager) is a <strong>free</strong> and fully featured file manager (applications, documents and multimedia) for both local and networked use. With over 300 million users worldwide, ES File Explorer (File Manager) claims to be the most powerful Android File Manager.</p>
<h2 style="text-align: center;">App requirements</h2>
<p style="text-align: justify;">This App is compatible with devices having android version 4.0 or up.</p>
<h3 style="text-align: center;">Where to get it? <span style="text-decoration: underline;">Download Link</span></h3>
<p style="text-align: justify;">You can download it for your Android Device by clicking on the following link of <a href="https://play.google.com/store/apps/details?id=com.estrongs.android.pop" target="_blank" rel="noopener noreferrer">Google Play </a>Store.</p>
<h2 style="text-align: center;"><b>Other features of ES
</b></h2>
<p style="text-align: justify;"><b>★ <span style="text-decoration: underline;">File Manager</span></b>: Install applications, check zipped files. It allows to install applications present in our storage.</p>
<b>★ <span style="text-decoration: underline;">Multimedia Explorer</span></b>: Play music/videos, check images, and documents, it eliminates the neccesity of 2 or 3 different applications required for running different types of media, like image viewer, r media player etc. ES has its own inbuilt video player,audio player and even a browser to open image and documents.
<p style="text-align: justify;"><b>★ <span style="text-decoration: underline;">Text viewers and editor</span>:</b>You can view or edit text files in ES.</p>
<b>★ <span style="text-decoration: underline;">Cloud Storage</span></b>: You can access your files saved on various online services through this app. It currently supports <a href="https://db.tt/aqZ6W0JC">Dropbox</a>, Google Drive, One Drive (Sky Drive), and many more.
<h6 style="text-align: center;">Make a Dropbox Account from given link and get 500MB extra space.</h6>
<b>★ <span style="text-decoration: underline;">Remote File Manager</span></b>: This feature allows one to wirelessly connect to any wifi enabled device. For e.g. you can access all the data from your personal computer, and copy data without USB cables, and without any app to be installed on other device.
<h4 style="text-align: justify;">Other Networking features</h4>
ES File Manager offers a plethora of choices in it's networking features, namely-
<ul>
 	<li style="text-align: justify;">Network</li>
 	<li>LAN</li>
 	<li>Cloud</li>
 	<li>FTP (File Transfer Protocol</li>
 	<li>Android TV</li>
 	<li>Bluetooth</li>
 	<li>Remote Manager (Mostly used)</li>
 	<li>Net Manager</li>
</ul>
<b>★ <span style="text-decoration: underline;">Built-in ZIP and RAR support</span></b>: ES allows one to compress and decompress ZIP files, unpack RAR files, and create encrypted ZIP files.
<p style="text-align: justify;"><b>★ <span style="text-decoration: underline;">Supports Multiple Languages</span></b>: English, Russian, Japanese, French, bla bla bla, Spanish, German, Italian, etc.</p>
<h3 style="text-align: center;">Other Features apart from File Managing</h3>
<p style="text-align: justify;"><b>► <span style="text-decoration: underline;">Kill tasks with a single click, increase memory and speed up your device</span></b>: Includes a simple widget that stays on your home screen to let you know your current RAM situation and automatically kill tasks, with an ignore list to ignore the applications you want to keep running.</p>
<p style="text-align: justify;"><b>► <span style="text-decoration: underline;">Cache Cleaner and Auto-start Manager</span></b>: Delete junk files that take up valuable storage space. The Task Manager module is required for this feature. Root Permission needed for Auto Start Manager.</p>
<p style="text-align: justify;"><b>► <span style="text-decoration: underline;">Root Explorer</span></b>: The ultimate set of file management tools for root users. Provides access to the entire file system and all data directories, and allows the user to change permissions. Root Permission needed for this feature.</p>
