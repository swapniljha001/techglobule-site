<h1 style="text-align: center;">Hi Guys,</h1>
<p style="text-align: justify;">In earlier posts, we discussed about the Android Operating System, today we will discuss about an other high-end mobile OS which is yet being developed, known as the <strong><a href="https://www.tizen.org" target="_blank" rel="noopener noreferrer">Tizen OS</a></strong>. It is a project within the Linux Foundation and is governed by a <strong>Technical Steering Group</strong> (TSG) composed of many multinational companies like <span style="color: #000000;"><a style="color: #000000;" href="http://samsung.com" target="_blank" rel="noopener noreferrer"><strong>Samsung</strong></a></span> and <span style="color: #000000;"><a style="color: #000000;" href="http://intel.com" target="_blank" rel="noopener noreferrer"><strong>Intel</strong></a> </span>among others. The Technical Steering Group is the primary decision-making body for the open source project, with a focus on platform development and delivery, along with the formation of working groups to support the device.</p>
<h2 style="text-align: center;">What is Tizen OS?</h2>
<p style="text-align: justify;">Tizen is an operating system based on the Linux Kernel (Linux Kernel in simpler words mean the most basic level or core of a Linux-based OS, and is responsible for resource allocation, file management, and security). It targets a very wide range of devices including smartphones, tablets, in-vehicle infotainment devices, smart TVs, PCs, smart cameras, wearable computing (such as smart watches), Blu-ray players, printers and smart home appliances (such as refrigerators, lighting, washing machines, air conditioners, ovens/microwaves, robotic vacuüm cleaners etc.). Its sole purpose is to offer a consistent user experience across various devices.</p>
<h2 style="text-align: center;">Who are the Developers of Tizen?</h2>
<p style="text-align: justify;">The <strong>Tizen Association</strong> was formed to guide the industrial role of Tizen, including requirements gathering, identifying and facilitating service models, and overall industry marketing and education.To make an Ultimate OS, it would need a huge amount of capital. Current members include Telecommunications network operators, Original Equipment Manufacturers like Fujitsu, Huawei, Intel, KT Corporation, NEC Casio Mobile Communications, NTT Docomo, Orange S.A., Panasonic Mobile Communications, Samsung, SK Telecom, Sprint Corporation and Vodafone.</p>
<h2 style="text-align: center;">Why is Tizen so special?</h2>
Tizen is an open and flexible OS built for the mobile and connected device ecosystem, including device manufacturers, mobile operators, application developers and independent software vendors (ISVs). Tizen is developed by a community of developers, under Open Source governance, and is open to all members who wish to take part.
This means if you are a developer you can help in developing Tizen too, at <a href="https://developer.tizen.org/" target="_blank" rel="noopener noreferrer">https://developer.tizen.org/</a>.
The Tizen operating system comes in multiple profiles to serve different industrial requirements. The current Tizen profiles are <strong>Tizen IVI</strong> (in-vehicle infotainment), <strong>Tizen Mobile</strong>, <strong>Tizen TV</strong>, and <strong>Tizen Wearable</strong>. Additionally, in <strong>Tizen 3.0</strong>, all profiles are built on top of a commonly shared infrastructure called <strong>Tizen Common</strong>.
With Tizen, a device manufacturer can begin with one of these profiles and change it to serve their own needs, or use the Tizen Common base to develop a new profile to meet the memory, processing and power requirements of any device and quickly bring it to market.
Mobile operators can work with device partners to customize the operating system and user experience to meet the needs of specific customer segments or demographics.
For application developers and ISVs, Tizen offers the power of native application development with the flexibility of <strong>unparalleled HTML5 support</strong>. Tizen also offers the potential for application developers to extend their reach to new “smart devices” running Tizen, including wearable, consumer electronics, cars, appliances etc.
<h3 style="text-align: center;">Main Features of Stock UI</h3>
The main features of the Tizen OS are as following -
<h4>Scene Management Feature -</h4>
The Tizen platform provides scene management as a feature which helps to:
<ul>
	<li>Enhance the form life-cycle management and also make the transitions between forms or panels much easier.</li>
	<li>Jump to a specific scene in an application, go back to the previous scene with or without skipping some scenes, or move to the next scene according to a predefined scenario.</li>
	<li>Add various transition animations for forms and panels.</li>
</ul>
<h4>GUI Controls -</h4>
You can display and interact with the UI controls (graphical user interface elements that are displayed inside the application frame). The UI controls are divided into 2 general classifications:
<ul>
	<li>
<h5>Container -</h5>
A container is a control that can contain controls and other containers to handle layout and presentation aspects. Containers have a parent-child relationship with the controls included in them.</li>
	<li>
<h5>Controls -</h5>
Controls are the real UI elements, such as lists and text fields, that can be added to containers. They provide user interaction functionality to an application. Controls cannot contain other controls.</li>
</ul>
<h4>Data Binding -</h4>
(Its kinda programming like stuff, non - geek users may skip this part.) You can place data into UI control properties at run time, and define the directions of the data flow and the triggers for the data transfer to start updating application data.
<ul>
	<li>You can define the size and place of the child controls within a container, and make sure that the layout of the child controls remains the same regardless of the screen orientation.</li>
	<li>You can use animation functionality handling to make the user interface rich. Animations can be implemented on both UI controls and visual element objects.</li>
	<li>Effects are based on an effect model, which has multiple model surfaces based on logical coördinates. You can define interactive and time-based 3D transition effects for your application.</li>
	<li><span style="color: #000000;">You can display input characters and symbols in applications. Additionally, you can use the input method editor to define a way to input a language in the associated text input UI control.</span></li>
</ul>
<h4>Accessibility -</h4>
Accessibility allows physically disabled users to use all the device functionalities normally. Tizen provides a large number of such features to such people. The most basic features are large fonts and the screen reader functionality to make applications accessible for visually impaired persons.
<span style="color: #000000;">Touch effect allows you to play predefined effects. If you make your own custom control, this functionality can help you to create feedback when, for example, buttons are pressed.</span>
